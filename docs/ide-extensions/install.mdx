NextCLI in VS Code is the open-source continuation of the Continue extension, maintained by the nextcli-dev organization. It does not use a Continue hub account and it does not sign you in. Model settings and rules are read from `~/.continue` on your machine, so a config you already wrote for Continue still applies.

The public Marketplace listing is not published yet. Until it is, install a `.vsix` you build from the [NextCLI repository](https://github.com/nextcli-dev/nextcli).

## Requirements

NextCLI 1.6.5 and later need **VS Code 1.101 or newer**, the first VS Code with Node.js 22. NextCLI 1.6.4 is the last version for VS Code 1.70 to 1.100.

Forks such as Cursor, Windsurf and VSCodium count by the VS Code version they are based on, which **Help > About** shows. Cursor 3.29, for example, is based on VS Code 1.128.

On an older VS Code, NextCLI stays on 1.6.4 and keeps working. From the Marketplace, VS Code installs the newest NextCLI that works with your VS Code version. With a `.vsix`, use the 1.6.4 release. To receive newer versions, update VS Code.

<Step title="Install the extension">
Package `extensions/vscode` in the NextCLI repository and install the `.vsix` from `extensions/vscode/build/`.

<Step title="Open NextCLI in VS Code">
After the VSIX is installed, the NextCLI logo appears in the sidebar.
</Step>

<Step title="Move to Right Sidebar">
The NextCLI logo will appear on the left sidebar. For a better experience, move NextCLI to the right sidebar

</Step>
