<Tab title="VS Code">

<Steps>
<Step title="Install from Marketplace">
Click `Install` on the [NextCLI extension page in the Visual Studio Marketplace](https://marketplace.visualstudio.com/items?itemName=Continue.continue)
</Step>

<Step title="Install in VS Code">
  This will open the NextCLI extension page in VS Code, where you will need to
  click `Install` again
</Step>

<Step title="Move to Right Sidebar">
The NextCLI logo will appear on the left sidebar. For a better experience, move NextCLI to the right sidebar

![move-to-right-sidebar](/images/move-to-right-sidebar-b2d315296198e41046fc174d8178f30a.gif)

</Step>

</Steps>

<Info>
  If you have any problems, see the [troubleshooting guide](/troubleshooting).
</Info>

</Tab>
</Tabs>

NextCLI does not ship a JetBrains plugin. In a JetBrains IDE, run the CLI (`cn`) in the terminal.
