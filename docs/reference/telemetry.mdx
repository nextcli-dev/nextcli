---
title: "Telemetry"
---

NextCLI sends no telemetry by default, and it has no endpoint of its own. Metrics go only to an OpenTelemetry (OTLP) collector that you run and configure.

## VS Code extension

The extension exports metrics only when all of these are true:

- **Allow Anonymous Telemetry** is on. Open the NextCLI settings, choose **User Settings**, and find it under **Telemetry**. It is off by default.
- VS Code's own telemetry is on (`telemetry.telemetryLevel` is not `off`).
- An OTLP endpoint is set in the environment VS Code starts with:

```bash
export OTEL_EXPORTER_OTLP_ENDPOINT="https://otel.example.com"
# optional: authentication for your collector
export OTEL_EXPORTER_OTLP_HEADERS="Authorization=Bearer <token>"
code .
```

Turning off either setting stops the exporter right away. **Allow Anonymous Telemetry** keeps your choice while VS Code's telemetry is off, and the switch shows that stored choice. Without an endpoint, no exporter is created and no telemetry request is made.

### Variables it reads

| Variable | Use |
|---|---|
| `OTEL_EXPORTER_OTLP_METRICS_ENDPOINT` | Full metrics URL. Takes precedence over the next one. |
| `OTEL_EXPORTER_OTLP_ENDPOINT` | Base URL; metrics go to `<base>/v1/metrics`. |
| `OTEL_EXPORTER_OTLP_HEADERS` | Headers as `key=value,key2=value2`, values %-encoded. |
| `OTEL_EXPORTER_OTLP_METRICS_HEADERS` | Same format; overrides `OTEL_EXPORTER_OTLP_HEADERS` per key. |
| `OTEL_METRIC_EXPORT_INTERVAL` | Milliseconds between exports. Default `60000`. |

Metrics are always sent as OTLP over HTTP with a JSON body. Other `OTEL_*` variables, including `OTEL_EXPORTER_OTLP_PROTOCOL` and `OTEL_EXPORTER_OTLP_METRICS_PROTOCOL`, are not read.

### What is sent

Counters named `nextcli_core_*`, with the resource attributes `service.name=nextcli-core`, `service.version` (the extension version) and `nextcli.ide`. Only metrics declared in the list below are recorded, and their attributes only take the values listed. Anything else, such as a file name, path, URL or text, is dropped before it is recorded.

No metrics are recorded yet. Features add their metrics to this list (and to `CORE_METRICS` in `core/util/telemetry/coreTelemetry.ts`) when they start recording them.

## CLI

The CLI (`cn`) exports metrics only when you set `CONTINUE_CLI_ENABLE_TELEMETRY=1` (or `CONTINUE_METRICS_ENABLED=1`) and an OTLP endpoint with `OTEL_EXPORTER_OTLP_ENDPOINT` or `OTEL_EXPORTER_OTLP_METRICS_ENDPOINT`. Its metrics are named `continue_cli_*`.
