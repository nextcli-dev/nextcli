## NextCLI CLI

<Note>Terminal-native AI coding assistance with TUI and headless modes.</Note>

<CodeGroup>

    ```bash npm
    npm i -g @nextcli/cli
    ```

    ```bash yarn
    yarn global add @nextcli/cli
    ```

    ```bash pnpm
    pnpm add -g @nextcli/cli
    ```

</CodeGroup>
