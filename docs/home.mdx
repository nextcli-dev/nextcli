## What is NextCLI?

**NextCLI enables developers to create, share, and use custom AI code agents with the CLI and the open source [VS Code](https://marketplace.visualstudio.com/items?itemName=Continue.continue) extension.** NextCLI does not ship a JetBrains plugin. In a JetBrains IDE, run `cn` in the terminal.

## Key Features

**You can use NextCLI to build and run custom agents across your IDE, terminal, and CI.**

1. Get started with NextCLI in the [VS Code](https://marketplace.visualstudio.com/items?itemName=Continue.continue) extension:
- [Agent mode](/ide-extensions/agent/quick-start) to work on development tasks together with AI
- [Chat mode](/ide-extensions/chat/quick-start) to ask general questions and clarify code sections
- [Edit mode](/ide-extensions/edit/quick-start) to modify code section without leaving your current file
- [Autocomplete](/ide-extensions/autocomplete/quick-start) to receive inline code suggestions as you type

2. Try out [NextCLI CLI (cn)](https://docs.nextcli.dev/guides/cli) and give us feedback
