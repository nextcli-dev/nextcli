## What is NextCLI?

NextCLI is an open-source coding agent for the terminal and VS Code, maintained by the nextcli-dev organization. It continues the Continue project after Continue Dev, Inc. stopped active maintenance. The CLI and the extension are free under the Apache License 2.0. You pay the model provider whose API key you put in your own config.

There is no NextCLI hub and no sign-in. Assistants, rules, and model settings stay in `~/.continue` on your machine. A config you already wrote for Continue still loads from that directory.

The CLI command is `cn`. The published package name is `@nextcli/cli`, not the old Continue package name.

## Install

- [CLI quickstart](/cli/quickstart) — shell installer, or `npm i -g @nextcli/cli` if you have Node.js 22.15 or newer
- [VS Code](/ide-extensions/install) — agent, chat, edit, and autocomplete in the editor

NextCLI does not ship a JetBrains plugin. In a JetBrains IDE, run `cn` in the terminal.

## What you can run

- [Agent](/ide-extensions/agent/quick-start) works through a task with the tools you allow
- [Chat](/ide-extensions/chat/quick-start) answers questions about the code you have open
- [Edit](/ide-extensions/edit/quick-start) changes the current file
- [Autocomplete](/ide-extensions/autocomplete/quick-start) offers inline completions as you type
